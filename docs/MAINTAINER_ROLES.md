## Decision Process

Substantial architectural changes, model additions, or template refactors should begin with a public GitHub issue or proposal discussion unless the topic involves a security vulnerability or sensitive data. Maintainers document accepted, deferred, and declined proposals with clear technical rationale.

## Maintenance Boundary

Maintainers may decline contributions that cannot be tested, reviewed, documented, or maintained within available lab and cluster compute resources.
