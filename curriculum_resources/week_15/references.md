Week 15 Resources
Evaluation & Documentation Prep

--------------------------------------------------

1. PyTorch Model Evaluation
https://pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html#test-the-network-on-the-test-data

Basic guide for evaluating PyTorch models with unseen data.

--------------------------------------------------

2. Scikit-learn Classification Report
https://scikit-learn.org/stable/modules/generated/sklearn.metrics.classification_report.html

Documentation for generating precision, recall, F1-score metrics.

--------------------------------------------------

3. Confusion Matrix Visualization
https://seaborn.pydata.org/examples/many_pair_plot.html

Guide for plotting confusion matrices using Seaborn heatmaps.

--------------------------------------------------

4. Matplotlib Heatmaps
https://matplotlib.org/stable/gallery/images_contours_and_fields/image_annotated_heatmap.html

Matplotlib heatmap tutorials for visualizing classification results.

--------------------------------------------------

5. Technical Documentation Best Practices
https://www.nngroup.com/articles/write-technical-documentation/

Advice on creating clear, readable documentation for projects.

--------------------------------------------------

Learning Goals

By the end of this week students should be able to:

• Evaluate model performance on unseen field images
• Generate classification reports and confusion matrices
• Visualize results for reports and presentations
• Begin drafting a video narrative for project documentation
