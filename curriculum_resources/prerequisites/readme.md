# AI Starter Kit (K–12 Friendly)

Welcome!  
Before starting the project, spend **~45–60 minutes** going through these resources.

By the end, you will:
- Understand what Artificial Intelligence (AI) is  
- Learn how computers “see” images  
- Try building your own simple AI model  
- See how AI is used in agriculture  

That’s all you need to confidently begin the project!

## 3. Try AI Yourself (Most Important)

Interactive (10–15 min)  
- Teachable Machine (by Google)  
https://teachablemachine.withgoogle.com/

**Activity:**
- Create 2 classes (e.g., Healthy Leaf vs Damaged Leaf)  
- Train your model  
- Test it using images or webcam  

 This will give you your first hands-on experience with AI!
